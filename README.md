> 🚧 **Building in public. Started on October 20, 2026.**
> I'm building this project in the open, one day at a time. Follow along in [PROGRESS.md](PROGRESS.md).

ClauseLens is an AI-powered contract intelligence system that helps people understand complex legal documents faster. It uses LLMs to extract, analyze, and explain important clauses, obligations, risks, dates, and key terms from contracts.

The project focuses on reliable GenAI engineering. It covers document processing, structured LLM outputs, retrieval, validation, and explainable AI workflows.

---

## Why ClauseLens?

Contracts are long, dense, and easy to misread. Important details like a renewal deadline, a liability cap, or a termination clause often sit deep inside pages of legal text. ClauseLens aims to:

- Surface what matters in a contract quickly
- Explain clauses in plain language
- Flag potential risks and unusual terms
- Show the source behind every answer, so nothing is a black box

## Planned Features

- [ ] **Document ingestion:** upload and parse contracts (PDF, DOCX, text)
- [ ] **Clause extraction:** identify and classify key clauses (termination, liability, confidentiality, payment, etc.)
- [ ] **Obligations & dates:** pull out who owes what, and by when
- [ ] **Risk analysis:** flag risky, missing, or unusual terms
- [ ] **Plain-language explanations:** explain legal text in simple words
- [ ] **Q&A over contracts:** ask questions and get answers grounded in the document (retrieval)
- [ ] **Structured outputs:** typed, schema-validated LLM responses
- [ ] **Validation & citations:** every answer traces back to the exact source text
- [ ] **Simple UI:** a clean interface to upload, explore, and review results

## What This Project Demonstrates

| Area | Focus |
| --- | --- |
| Document processing | Parsing, chunking, and cleaning real-world contracts |
| Structured LLM outputs | Schema-driven extraction instead of free-form text |
| Retrieval | Finding the right parts of a document to answer a question |
| Validation | Checking LLM outputs for correctness and consistency |
| Explainability | Linking every insight back to the original clause |
